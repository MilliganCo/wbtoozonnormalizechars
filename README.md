# WB to Ozon Normalize Chars

> Public experimental source: see [PUBLICATION.md](PUBLICATION.md) for actual checks, known defects, restored modules and operational limits. Earlier audit decisions are historical.

## О проекте

`WB to Ozon Normalize Chars` — утилита для переноса и нормализации данных между Excel-шаблонами Wildberries и Ozon. Судя по коду, основной сценарий использования — взять выгрузку или шаблон WB, сопоставить поля с форматом Ozon и автоматически преобразовать размеры, веса, артикулы и часть текстовых характеристик.

## Что делает скрипт

- хранит словарь соответствий между колонками WB и Ozon;
- нормализует отдельные типы значений;
- склеивает и преобразует поля размеров;
- переводит килограммы в граммы и сантиметры в миллиметры;
- обновляет только данные в Ozon-файле, не ломая структуру шаблона;
- сохраняет обновлённый результат в отдельную папку `updated`.

## Стек и структура

- Python
- `pandas`
- `openpyxl`
- `tkinter`
- основной файл: `wb_to_ozon.py`

## Запуск

```bash
python wb_to_ozon.py
```

## Статус

Готовая прикладная утилита. Проект выглядит как инструмент для ручной или полуавтоматической подготовки карточек товара под Ozon на основе данных из WB.
